# 📖 Overview

F.O.R.G.E. (**Forensic Observation and Recognition Gateway for Emerging Generative Exploits**) is a **multimodal AI-powered forensic platform** developed at **C-DAC (MeitY)** to assist investigators, researchers, and cybersecurity professionals in detecting synthetic media.

Unlike conventional deepfake detectors that simply classify media as *Real* or *Fake*, FORGE performs **forensic intelligence analysis**, generating:

- Explainable AI visualizations
- Parameter-level reasoning
- Confidence analysis
- Sentence-level explanations
- Audio forensic evidence
- Image heatmaps
- Comprehensive PDF investigation reports

# ✨ Features

## 📝 Text Forensics

Detect AI-generated and manipulated text using multiple linguistic signals.

### Capabilities

- Stylometric Analysis
- TF-IDF Vector Analysis
- Sentence-BERT Semantic Embeddings
- N-Gram Diversity Analysis
- Explainable AI Parameter Reasoning
- Sentence-Level Risk Heatmaps
- Copy/Paste Text Analysis
- DOCX Support
- PDF Support
- TXT Support

---

## 🖼 Image Forensics

Detect synthetic images and manipulated photographs.

### Features

- EfficientNetB0 Feature Extraction
- Random Forest Classification
- Grad-CAM Heatmaps
- Confidence Scores
- Image Explanation Engine
- OCR Support
- Metadata Analysis

---

## 🎙 Audio Forensics

Detect AI-generated speech and cloned voices.

### Features

- CNN + BiLSTM Hybrid Architecture
- LFCC Feature Extraction
- 27 Acoustic Parameters
- Spectrogram Analysis
- Waveform Visualization
- Audio Confidence Estimation
- Explainable Parameter Contribution
